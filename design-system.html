Design system

ANAND Design System

The tokens, type, components, motion and writing rules behind the ANAND website. Every specimen on this page is drawn with the live site styles, so it can't drift from the pages it describes. The written reference is HANDOFF.md §5–§7.

Copy Stripe Precisely

When a section follows Stripe, match its interaction, timing, easing and proportions. Measure the real values; don't reinterpret.

Clean, Not Decorated

Flat tiles, few shadows, no glows. No gradient text, ever: gradients are for shapes only.

One Light Blue

The logo cyan #00AEEF is the only light blue. Anything with a blue fill carries white text.

Tokens Only

Every colour, font size and radius is a token. No raw pixel font sizes, no stray hex values.

Neutral Hovers

Hover adds a light grey fill and a text colour change. Borders never turn brand-coloured.

Real Content Only

Copy comes from anandgroupindia.com, the Jan 2026 corporate presentation and thesujanlife.com. Nothing invented.

Colour

Colour Tokens

Hex values below are read from the live stylesheet. Navy and cyan carry the brand; green is for sustainability only. The rules use these tokens, never raw hex.

Brand

Text and Neutrals

CSR Card Pairs

A fill plus a lighter tint for the ANAND chevron mark (at 55%). Used by the CSR cards, the newsroom coverage carousel and Recent Highlights. The only hardcoded colours in the system.

Typography

Geist, on One Scale

Geist is the only typeface. Every font size is a token; the size column shows what each one renders at on this screen. Fluid sizes use clamp() and shrink on smaller screens.

Motion

Easing and Timing

Measured from Stripe where a section copies it. Sections fade up on scroll. Everything respects reduced motion.

Language

Voice, Case and Facts

Confident, factual, restrained. Short sentences, no hype. UK/Indian English: programme, honours, enquiries, lakh.

Case

  • Title Case for headings, card titles and every button or link label: "Partner with Us", "See All News".
  • Small words stay lowercase unless first: a, an, the, and, or, for, of, on, in, to, at, by, with. Units stay lowercase: "sq km", "mn".
  • Title Case for top-level nav labels and footer column headings ("Our Companies").
  • Sentence case for the items inside menus and footer link lists.
  • All caps for eyebrows and in-card labels, through CSS only.
  • Press headlines keep the publisher's own casing.

Spelling and Numbers

  • Currency: US$2.2B+, US$408M; never $2.2 bn. Rupee figures follow the source.
  • Brands: ANAND, SUJÁN, Gabriel India, ANEVOLVE, HL Klemove, MAHLE ANAND, Joyson ANAND.
  • ANEVOLVE in caps as the platform; the company keeps "Anevolve Mando eMobility".
  • "People", not "employees". "Our Vision" in the nav; the section eyebrow reads "Vision & strategy".
